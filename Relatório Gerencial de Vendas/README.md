Sobre o projeto:

Este projeto foi desenvolvido como parte do desafio do Bootcamp Santander — Primeiros Passos em Power BI, com o objetivo de aplicar conceitos de Business Intelligence, análise de dados e visualização de informações utilizando o Power BI. A partir do dataset Financials, foi desenvolvido um dashboard interativo para transformar dados de vendas e resultados financeiros em informações visuais que facilitem a compreensão do desempenho do negócio. O projeto permite analisar os resultados sob diferentes perspectivas, possibilitando identificar tendências, comparar segmentos, avaliar produtos e compreender a distribuição das vendas por localização.

Objetivos
* Analisar o desempenho de vendas;
* Acompanhar indicadores financeiros;
* Identificar os produtos com maior participação nas vendas e nos lucros;
* Comparar o desempenho entre segmentos;
* Analisar resultados por país;
* Avaliar a evolução dos indicadores ao longo do tempo;
* Utilizar recursos de interatividade para facilitar a exploração dos dados;
* Aplicar conceitos de Data Visualization, Business Intelligence e Storytelling com Dados.
