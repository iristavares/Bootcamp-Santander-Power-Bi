O Relatório de Vendas apresentado foi desenvolvido no Power BI como desafio final do bootcamp, cujo objetivo era atualizar um relatório financeiro criado anteriormente com foco na experiência do usuário. A proposta foi reorganizar os visuais de modo que as informações mais importantes sejam encontradas rapidamente e que a exploração dos dados seja simples e agradável, aplicando conceitos de posicionamento, contraste, proporção áurea e segmentação dos dados.
