Este projeto consiste na atualização de um relatório de vendas desenvolvido no Power BI, com foco na melhoria da experiência do usuário, na organização visual das informações e na interatividade dos dashboards.

O desafio teve como objetivo aprimorar um relatório existente, aplicando princípios de design e visualização de dados para tornar a análise comercial mais intuitiva, organizada e eficiente.

## Objetivos do Projeto

- Aprimorar a organização e o posicionamento dos elementos visuais.
- Melhorar o contraste e a proporção entre os componentes do relatório.
- Implementar segmentações para facilitar a análise dos dados.
- Desenvolver indicadores e gráficos que facilitem a interpretação dos resultados.
- Criar recursos de navegação para melhorar a experiência de uso.
- Padronizar a identidade visual das páginas do relatório.
